How to compress to 100KB

  1. Add a JPG, PNG, WebP or BMP image.
  2. 100KB is selected as the maximum size.
  3. Squish searches image quality and reduces dimensions only if needed.
  4. Preview and download the compressed file.

Better than guessing with a quality slider

A quality setting such as 70% does not correspond to a predictable file size. Squish checks the encoded result and adjusts toward the size requirement instead.

Browser-based processing

The exact-size compressor processes the selected image with the browser Canvas API. Re-encoding also removes most embedded EXIF metadata such as camera and GPS fields.
