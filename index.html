Privacy, explained clearly

Use the right processing mode.

The exact-KB compressor runs in your browser using the Canvas API, so files selected there stay on your device. The advanced resizer uses a short-lived Vercel server function with Sharp to support more formats and processing options.

Why the distinction mattersThe compressor naturally strips most embedded EXIF metadata when it re-encodes the image. The advanced resizer sends the file for processing and does not intentionally store it. Choose the workflow that fits your needs.

FAQ

Image compression questions.

Can I compress an image to exactly 100KB?

The compressor targets a maximum size, such as 100KB, and tries to preserve the highest quality possible while staying at or below that limit. Exact byte-for-byte output is not always possible because image encoders work in discrete quality steps.

Does compressing an image change its dimensions?

Squish first reduces encoding quality. If even the lowest useful quality is still above your requested size, it gradually reduces pixel dimensions until the output fits.

Which formats work with the exact-size compressor?

Modern browsers reliably handle JPEG, PNG, WebP and BMP input. The compressor exports JPEG or WebP for predictable size control.

Is the image uploaded?

The exact-size compressor processes selected files in the browser. The advanced resize tool uses a server-side Sharp function because it supports a broader format and resize feature set.
